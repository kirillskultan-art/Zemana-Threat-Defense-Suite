## 🧪 Troubleshooting Playbook

### Installer Does Not Launch

Try running as administrator. Temporarily pause other security agents that may be intercepting the setup process.

### Scan Seems Stuck

Large disks with millions of files can take a while. Let the scan complete or pause and resume.

### Real-Time Protection Shows Off

Check for conflicting security software. Some combinations require mutual exclusions.

### Updates Fail

Verify network connectivity and firewall rules. Corporate networks sometimes block update endpoints.
